# Franka Web

用 Rust 为 Franka 机器人开发操作网页，参考 [cobot-web](https://github.com/ajwwja777/cobot-web) 的使用体验与模块组织。

## 项目目标

围绕设备状态、相机预览、任务操作、数据采集、模型部署和日志展示逐步构建统一操作入口。具体首版功能与验收方式在设计阶段确认。

Rust 是已确定的技术方向。服务框架、前端技术以及机器人接口适配方案将在核对现有系统后确定。项目负责网页、服务接口与操作编排，复用已有控制和模型能力。

## 文件组织

代码、配置示例和文档按实际需要增加；Rust 构建产物、现场配置和运行输出不入库。机器访问与现场接管信息保存在不入库的 `LOCAL_HANDOFF.md` 中，由项目维护者在对应工作区提供。
